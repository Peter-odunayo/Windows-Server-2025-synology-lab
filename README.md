# Windows-Server-2025-synology-lab
Hybrid file server lab using Windows Server 2025, Active Directory, and Synology NAS with role-based access control


# Hybrid Enterprise IT Lab

This project simulates a real-world enterprise IT environment using:

- Windows Server 2025 (Active Directory)
- Windows 11 Clients
- Synology NAS (DSM)
- Ubuntu Server

## Project Goal
To build a hybrid infrastructure with identity, storage, security, and (later) cloud integration.
